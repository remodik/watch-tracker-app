## Проверки и состояние выпуска

Первая попытка локального прогона исходной ветки прервалась из-за заполнения диска. Для исходного SHA `0113a65` также доступен зелёный прогон backend и frontend в GitHub Actions. [Исходный CI](https://github.com/remodik/watch-tracker-app/actions/runs/45460963141)

- Новые ревизии `0003_edit_revision` добавляет токен редактирования и поколение коллекции. `0004_backup_size` добавляет размер и SHA-256 снимков. Штатные записи, ID и даты сохраняются.
- `alembic upgrade head`, `alembic check`, прерванная SQLite-миграция, конкурентный SQLite upgrade, PostgreSQL `pg_dump` и `pg_restore` проверены на изолированных данных.
- `npm ci`, Prettier, Ruff, Playwright, axe, `pip-audit`, `npm audit` и Gitleaks выполнялись локально. Отдельные запуски pytest использовали локальный PostgreSQL 16.
- Синтетические замеры SQLite с 2 000 строк дали шесть SQL-запросов для dashboard, два для статистики и выдачи, три для экспорта, пять для снимка. В набор входил экспорт размером 18,4 МБ. Серверное восстановление в той среде занимало около 3,5 с.
- Вмешательство в реальные базы и развёртывания не требовалось. Доступ к логам ограничен запусками данного PR. История доступных веток проверена без переписывания.

**Merge.** Локальные регрессии, миграции и PWA проверены, но проверка фактического reverse proxy и репетиция с историческими данными владельца остаются открытыми. Часть дополнительных пограничных тестов перечислена по строкам реестра. Выпуск через merge пока не рекомендован.

**Production.** Не сертифицирован без проверки копии фактической базы и топологии прокси. Процедуры подготовки, переключения базы и отката приведены в [инструкции](deployment.md).

**Публичная публикация.** В доступной истории и трёх проверенных логах Gitleaks не нашёл совпадений. Перед открытием репозитория подтвердите условия распространения данных и графики внешних провайдеров и сохранение AGPL-3.0 в результирующем дереве.
